## Week 1 Overview

Week 1 focuses on development environment setup, Git and GitHub fundamentals, and HTML5 basics.

As part of this week, I created a personal profile webpage using semantic HTML5 and practiced using Git and GitHub for version control and project management.

## Task Description

The main objectives of Week 1 were to:

* Set up a development environment using Visual Studio Code and Git.
* Create and configure a GitHub repository.
* Practice essential Git commands and version control.
* Build a personal developer profile webpage using HTML5.
* Use semantic HTML elements and basic accessibility practices.
* Document the project and learning progress.

## Key Learnings

During Week 1, I learned and practiced:

* Basic HTML5 document structure.
* Semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
* Creating headings, paragraphs, lists, links, and forms.
* Using labels and appropriate input types for better accessibility.
* Initializing and managing a Git repository.
* Staging files using `git add`.
* Creating commits using `git commit`.
* Connecting a local repository to GitHub.
* Pushing project changes to a remote GitHub repository.
* Maintaining meaningful Git commit history.

## Difficulties and Blockers

One of the challenges during setup was GitHub authentication. The local Git repository was initially authenticated with a different GitHub account, which caused a permission error when pushing the project.

I resolved the issue by authenticating with the correct GitHub account and updating my Git identity so that the commit history correctly represents the project author.
